## 🆕 ما الجديد في الإصدار 3 (v3.0.0)

- **سرعة أعلى على الموبايل:** وضع خفيف تلقائي (`perf-lite`) للموبايل والتابلت والأجهزة الضعيفة — إيقاف تأثيرات الـ blur الثقيلة (backdrop-filter، الكرات المضيئة blur 140px، خلفية البوستر)، إيقاف الـ parallax أثناء التمرير، تقليل جزيئات الكانفاس وإلغاء الـ glow فيها، وإيقاف كل الأنيميشن الخلفية أثناء فتح وضع السكرول أو النوافذ.
- **وضع السكرول (Scroll Mode) اتعمل من جديد:** فيديو واحد فقط شغال في أي لحظة (الفيديو السابق بيتشال بالكامل فمستحيل الأصوات تتداخل)، الفيديوهات اللي بتعدي عليها بسرعة مش بتتحمل أصلاً، الصور بتتحمل بس للفيديو الحالي واللي جنبه، زر كتم الصوت بيعرض الحالة الصح، تشغيل/إيقاف بيعتمد على حالة الفيديو الحقيقية، دعم إعلانات Instagram و TikTok، وإصلاح ترتيب العداد `1 / 98` والتصميم على الموبايل.
- **شريط اللوجوهات والآراء:** محرك حركة جديد ناعم (transform بدل scrollLeft) بيقف لوحده لما يكون برا الشاشة، واللوجوهات بقت جوه المربعات بتاعتها على الموبايل من غير ما تطلع برا.
- **إصلاحات:** نصوص عربي كانت متكسرة (ترميز)، صورة ناقصة في قسم الميديا، تحميل كسول للصور، و`?v=3.0.0` على ملفات CSS/JS عشان الموبايلات تجيب النسخة الجديدة مش القديمة من الكاش.

## 🚀 كيفية الرفع والنشر المباشر على GitHub Pages

المشروع جاهز ومُهيّأ بالكامل للنشر الفوري كـ Static Website عبر **GitHub Pages**:

1. أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub (مثلاً: `altony-portfolio`).
2. قم برفع كافة ملفات هذا المجلد:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Altony Portfolio v3"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/altony-portfolio.git
   git push -u origin main
   ```
3. من صفحة المستودع على GitHub:
   - اذهب إلى **Settings** ⚙️ > **Pages**.
   - تحت **Build and deployment** > **Branch** اختر `main` والمسار `/ (root)`.
   - اضغط **Save**.
4. خلال ثوانٍ سيصبح موقعك متاحاً ومباشراً للعالم عبر رابط:
   `https://YOUR_USERNAME.github.io/altony-portfolio/`

## 💻 التشغيل والمعاينة المحلية (Local Development)

يمكنك تشغيل الموقع محلياً على جهازك بأي من الطرق التالية:
1. **تشغيل مباشر:** فتح ملف `index.html` في أي متصفح، أو الضغط مرتين على `افتح_الموقع_مباشرة.bat`.
2. **سيرفر محلي (مُوصى به):** الضغط مرتين على ملف `تشغيل_الموقع.bat` لبدء سيرفر محلي فوري على المنفذ `8000` (`http://localhost:8000`).
